Navigation model Four bottom tabs — Ledgers, Balances, Insights, You — plus a persistent FAB for add-expense, which is the only action frequent enough to deserve permanent screen space.

Balances tab holds cross-ledger net positions per friend and bulk settle. It is deliberately separate from Ledgers, because "what do I owe Rahul overall" is a different question from "what happened on the Goa trip".

You holds profile, UPI VPA, devices, notifications, archived ledgers, export, and — for the instance owner only — the admin panel. Everything infrequent lives here so the other three tabs stay clean.

Add expense is three taps from cold: FAB → type or fill → Save. The natural-language line is offered first and the structured form sits directly beneath it, so neither path is hidden behind the other.

Why? affordance on every suggested transfer, because simplified debts are always on and this is the answer to the one complaint that model reliably generates.
